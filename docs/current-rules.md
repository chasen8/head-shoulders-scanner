# 目前的頭肩底偵測規則（template profile，2026-10-19）

由 `ihs_scanner/config.py` 的實際生效值整理（`DEFAULT_CONFIG`）。改規則後要同步更新本檔。
符號：LS 左肩低點、N1 左頸線高點、H 頭部低點、N2 右頸線高點、RS 右肩低點；
neck(i)＝N1–N2 連線在第 i 根的價格；頭高＝neck(H) − H；頭到頸線漲幅 head_rise＝neck(H)/H − 1。

## 1. 找轉折點（swing）

|---|---|---|---|---|
| 低點 | low 嚴格小於左右各 N 根 | N=5 | 5 | 3 |
| 高點 | high 嚴格大於左右各 N 根 | 5 | 5 | 3 |
| 確認 | 右邊 N 根走完才算確認（最後 N 根不產生轉折點） | | | |

## 2. 五點怎麼選
- LS、H、RS 是低點，N1、N2 是高點，時間順序 LS < N1 < H < N2 < RS。
- **H 是 LS～RS 整段最低**；而且 LS 之前 0.5×(H−LS) 根內也不能有比 H 更低的 low（T8）。
- **N1**＝LS 之後第一個高點，且 LS 是 [LS, N1] 最低（T7：左肩就是衝向 N1 那段的起點）。
- **N2**＝H 與 RS 之間最高的高點。
- **RS**：已確認的低點；或 N2 確認後，「N2 之後到現在的最低點」暫定為 RS（右肩形成中，T6）。

## 8. 突破、狀態、失效
| 項目 | 規則 |
|---|---|
| 突破 | RS 之後收盤 > 頸線 × (1 + 緩衝)；緩衝 4h 0.5%／1d 1%／1w 1% |
| 成交量過濾 | 預設**關閉**（開啟時突破量 ≥ 前 20 根均量 × 1.2） |
| 右肩形成中 forming | RS 暫定；跌破 H 型態作廢；期間就算收盤站上頸線仍標 forming |
| 右肩已確認 watchlist | RS 確認、未突破，RS 後 ≤ 4h 30／1d 20／1w 8 根 |
| 已突破 confirmed | 從**第一次**收盤站上頸線起算 ≤ 4h 6／1d 5／1w 3 根（不重新計時） |
| 過期 stale（不顯示） | 超過上面的根數；或已漲超過頸線 0.5 × 頭高（V3b）；或突破後跌回頸線下 0.25 × 頭高以上（V3c） |
| 失效 | 突破前任何 low 跌破 RS（已確認的右肩）→ 型態作廢 |
| 去重 | 同幣同週期、左肩到右肩時間重疊的型態只留最高分 |
