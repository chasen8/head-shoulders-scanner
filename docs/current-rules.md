# 目前的頭肩底偵測規則（template profile，2026-10-25，含 D36、D45）

由 `ihs_scanner/config.py` 的實際生效值整理（`DEFAULT_CONFIG`）。改規則後要同步更新本檔。
符號：LS 左肩低點、N1 左頸線高點、H 頭部低點、N2 右頸線高點、RS 右肩低點；
neck(i)＝N1–N2 連線在第 i 根的價格；頭高＝neck(H) − H；頭到頸線漲幅 head_rise＝neck(H)/H − 1。

## 1. 找轉折點（swing）

|---|---|---|---|---|
| 低點 | low 嚴格小於左右各 N 根 | N=5 | 5 | 3 |
| 高點 | high 嚴格大於左右各 N 根 | 5 | 5 | 3 |
| 確認 | 右邊 N 根走完才算確認（最後 N 根不產生轉折點） | | | |

## 2. 五點怎麼選
- LS、H、RS 是低點，N1、N2 是高點，時間順序 LS < N1 < H < N2 < RS。
- **H 是 LS～RS 整段最低**；而且 LS 之前 0.5×(H−LS) 根內也不能有 K 線**實體**（min(開,收)）低於 H（T8；D36 前用 low，單根閃崩長下影會誤擋，例 LDO 1w 2025-10-06）。
- **N1**＝LS 之後第一個高點，且 LS 是 [LS, N1] 最低（T7：左肩就是衝向 N1 那段的起點）。
- **N2**＝H 與 RS 之間最高的高點。
- **RS**：已確認的低點；或 N2 確認後，「N2 之後到現在的最低點」暫定為 RS（右肩形成中，T6）。

## 8. 突破、狀態、失效
| 項目 | 規則 |
|---|---|
| 突破（D36） | RS 之後某根 **最高價（含影線）** > 頸線 × (1 + 緩衝)；緩衝 4h 0.5%／1d 1%／1w 1%（`breakout_price`=`close` 可改回收盤）。T4／V3a 是型態成立前的檢查，不變 |
| 突破優先（D36 B） | 同一個 H 的另一個有效候選 A 已在第 c 根穿越自己的頸線，RS 在 c 之後的候選 B 不成立（B＝突破後回測，N2 多半是突破後高點）。例外：A 的突破失敗（c～RS_B 之間 low < A 的 RS），或 B 的頸線排名較好（下斜優於上斜，再比碰頸線次數多；使用者 TRUST 範例） |

# 收斂三角（上升／下降／對稱三角，D38，2026-10-22）

由 `ihs_scanner/config.py` 的 `TRIANGLE_CONFIG`（與頭肩底設定完全分開）整理；程式 `ihs_scanner/triangles.py`，設計依據
`docs/triangle-research.md` 第 5–7 節（數值是該報告的建議初值，**不是**文獻直接給的，待使用者範例校準）。改規則後要同步更新本節。
符號：價格一律取自然對數；s＝型態第一個轉折點（高或低）；R(x)／S(x)＝阻力線／支撐線；H0＝R(s) − S(s)（起點寬度，對數）；
頂點 apex＝兩線交點；收斂進度 p(x)＝(x − s)／(apex − s)；收斂比例 ρ＝1 − p。

## 1. 轉折點與觸碰
| 項目 | 規則 | 4h | 1d | 1w |
|---|---|---|---|---|
| 轉折點 | 同頭肩底：嚴格高於／低於左右各 N 根，N 根後才確認 | N=5 | 5 | 3 |
| 觸碰點數 | 阻力線 ≥ 2、支撐線 ≥ 2、合計 ≥ 5（Bulkowski 3+2、Lo 2000 五個極值） | | | |
| 擬合 | s 之後的高點轉折做最小平方法得 R、低點轉折得 S（對數價） | | | |
| 觸碰容忍 ε | max(0.3 × ATR(14)/收盤, 0.5%)，ATR 取最新一個轉折確認那根 | | | |
| 剔除 | 殘差 > ε 的轉折剔除後重擬合，每條線最多 2 次；起點 s 不可被剔除 | | | |
| 貼外緣 | 擬合後把線平移，使觸碰點高出阻力線（或低於支撐線）不超過 1%；平移後殘差仍要 ≤ ε | | | |

## 2. 分類（漂移＝線在第一個到最後一個觸碰點之間的變化 ÷ H0）
| 類型 | 阻力線 | 支撐線 | 偏向 bias（只是標籤） |
|---|---|---|---|
| 上升三角 ascending | \|漂移\| ≤ 0.15（水平） | 漂移 ≥ +0.30 | up（傳統偏多） |
| 下降三角 descending | 漂移 ≤ −0.30 | \|漂移\| ≤ 0.15（水平） | down（傳統偏空；Bulkowski 實測 53% 向上突破） |
| 對稱三角 symmetrical | 漂移 ≤ −0.20 | 漂移 ≥ +0.20，且兩線每根斜率大小比 ≤ 3 | neutral |
| 其他（楔形、通道、矩形、介於水平與傾斜之間） | 不輸出 | | |

## 3. 收斂、寬度、長度
| 規則 | 門檻 |
|---|---|
| 兩線往右收斂 | 支撐線斜率 > 阻力線斜率；起點寬度 H0 > 0 |
| 收斂進度 | 收斂中：0.25 ≤ p < 1（ρ ≤ 0.75，至少收斂 25%）；突破那根也要 0.25 ≤ p ≤ 1；p ≥ 0.80（ρ < 0.20）標 `near_apex`（接近頂點），仍列出 |
| 寬度 | H0 ≥ 2 × ATR/收盤（不是雜訊）；e^H0 − 1 ≤ 80% |
| 起點對齊 | 第一個阻力觸碰與第一個支撐觸碰相差 ≤ 0.5 × (最後一個觸碰 − s) 根 |
| 長度（s 到現在；已突破則到突破那根） | 4h 24–200 根（台股 4h 上限 120）、1d 20–120、1w 10–60 |

## 4. 包住（價格被兩線夾住）
最新一個轉折確認之前的每一根（從 s 起）：收盤 ≤ R×1.005 且 ≥ S×0.995；最高 ≤ R×1.01、最低 ≥ S×0.99（沿用頭肩底 V3a 0.5%／T4 1%）。
確認之後到現在的 K 線只檢查突破；收盤超出 0.5% 但沒超過突破緩衝時仍算收斂中。

## 5. 突破與狀態
| 狀態 | 條件 |
|---|---|
| 突破 | 最新轉折確認後，第一根 收盤 > R×(1+緩衝)（向上）或 收盤 < S×(1−緩衝)（向下）；緩衝 4h 0.5%／1d 1%／1w 1%；`breakout_price`="high" 改用最高／最低價（預設 close，Bulkowski 用收盤）。同一根兩邊都穿＝不成立。第一次突破後不再加入新轉折、不重新計時 |
| 收斂中 forming | 未突破，0.25 ≤ p < 1，長度在範圍內 |
| 向上突破 breakout_up／向下突破 breakout_down | 突破後 ≤ 4h 6／1d 5／1w 3 根（同頭肩底） |
| 已過期 stale（不顯示） | `apex`：走到頂點（p ≥ 1）沒突破；`breakout_age`：超過上面根數；`failed_breakout`：突破後任一收盤回到被突破線內側超過 0.25 × H0 |
| 成交量 | 不使用（Bulkowski 的量縮只是統計描述；台股 4h 量為近似值） |

## 6. 目標價與失效價
| 項目 | 公式 |
|---|---|
| 高度 | 上升：R(s) 價 − 型態內最低轉折低點；下降：型態內最高轉折高點 − S(s) 價；對稱：最高轉折高點 − 最低轉折低點（Bulkowski measure rule） |
| 方向 | 已突破＝突破方向；未突破＝偏向方向（對稱三角用向上），欄位 `target_direction`，`target_estimated`=true |
| 突破價 | 突破那根的線價（向上＝R，向下＝S）；未突破時＝目前 R（或 S）價，所以目標是預估 |
| 目標價 target | 突破價 ± 高度 |
| 保守目標 target_conservative | 突破價 ± 高度 × Bulkowski 達標比例：上升 70%（上破）／44%（下破）、下降 64%／50%、對稱 58%／36%（thepatternsite.com，美股日線牛市，僅供參考） |
| 失效價 | 向上：型態內最後一個轉折低點；向下：上升三角＝突破那根（或現在）的阻力線價，其他＝型態內最後一個轉折高點 |
| 目標 ≤ 0 | 輸出 null |

## 7. 去重
同幣、同來源、同週期，[起點, 結束]（結束＝突破那根或現在）時間重疊的三角形只留一個：觸碰點多 → 平均擬合誤差（|殘差|/ε）小 → 起點較新 → 分數。
先排除 stale（除非 `include_stale`）再去重。三角形與頭肩底互不去重。

## 8. 分數（0–100，排序用）
| 分項 | 滿分 | 公式（clip 到 0–1） |
|---|---|---|
| 觸碰次數 touch_score | 20 | 20 × (觸碰數 − 4) / 4：5 點 5 分、8 點以上滿分 |
| 貼線程度 fit_score | 15 | 15 × (1 − 兩線平均 \|殘差\|/ε) |
| 收斂程度 convergence_score | 20 | 20 × (1 − \|ρ − 0.40\| / 0.35)，ρ 取突破那根（或現在） |
| 型態填滿 fill_score | 15 | 15 × 收盤穿越中線 (R+S)/2 次數 / (觸碰數 − 1) |
| 突破／接近突破 breakout_score | 20 | 已突破 20；否則 20 × (1 − d)，d＝偏向那條線的距離 ÷ 目前寬度（中性取較近一條 × 2） |
| 類型明確 clarity_score | 10 | 離分類門檻多遠：上升＝平均(1 − \|阻力漂移\|/0.15, (支撐漂移 − 0.30)/0.30)；下降鏡像；對稱＝平均((−阻力漂移 − 0.2)/0.2, (支撐漂移 − 0.2)/0.2, 1 − (斜率比 − 1)/2) |

## 1. 追蹤對象

| 頭肩底 | status＝confirmed | tp1（對數斐波那契 1.414） | tp2 | invalidation_price（H.low） | `breakout_level`＝突破那根的頸線價 |
| 收斂三角 | status＝breakout_up（向下突破不追蹤） | target_conservative | target | invalidation_price | `breakout_price`＝突破那根的阻力線價 |

- D36 起頭肩底的 `breakout_price` 是突破 K 線的 **high**（影線穿過即突破），可能遠高於頸線（例 NMR 1w 頸線 11.05、high 15.50），
  所以漲幅一律從**線上的價格**算，high 只另存 `breakout_bar_high`。
- 以 `pattern_id` 為鍵；每次掃描把新出現的加入，已在追蹤的不重複加入。結束的項目保留 90 天（`prune_days`）再刪，避免仍在清單上的型態被重新加入。

## 2. 判斷（只用已收盤 K 線，從突破那根開始，依序）
| 狀態 | 這根 K 線 | 結果 |
|---|---|---|
| open | low ≤ 失效價 | failed，結束（同一根也碰到 TP 時一樣算 failed：無法得知盤中先後，保守處理） |
| open | high ≥ TP2 | 記 TP1（high 也 ≥ TP1 時）與 TP2，結束 |
| open | high ≥ TP1 | tp1，繼續追 TP2 |
| tp1 | low ≤ 失效價 | failed，結束（TP1 事件保留；同根碰 TP2 也算 failed） |
| tp1 | high ≥ TP2 | tp2，結束 |
| 任一 | 突破後第 N 根仍未結束 | expired（N：4h 180、1d 120、1w 52，`max_bars`） |

- 突破那根本身算第 0 根：價格必須先穿過線才能到上方的目標，所以突破當根的 high 碰到 TP 也算達成。
- 每次執行都從頭重算（同樣的 K 線一定得到同樣結果），as-of t 只用到第 t 根以前的 K 線（截斷測試鎖住）；已記錄的事件不重複通知。

## 3. 通知
- 通知 TP1、TP2；failed 預設只記錄（`notify_failed=True` 才通知）；expired 只記錄。
- 首次執行（沒有追蹤檔）與事件發生在型態 `signal_time` 之前（型態還沒被看到）：只記錄不通知。
- 送不出去（沒有機器人、找不到頻道、Discord 拒絕）時該型態維持原狀態，下次執行重算後再送。

# 實際戰績頁與系統通知（D41，2026-10-23）

## 實際戰績（`ihs_scanner/track_record.py`，不改任何偵測或止盈判斷）
- 每次止盈追蹤後，由追蹤檔產生 `site/data/track_record.json`（台股 `site/data/tw/`），隨各自市場發布、互不覆蓋（`scripts/merge_published.py`，與追蹤檔同樣「這次沒產生就保留已發布的」）。
- 追蹤檔補記 `last_close`（最近一根已收盤 K 線的收盤價，給「追蹤中」的報酬用）；舊檔沒有這欄、也沒有過期收盤的，報酬標「未知」。已結束項目保留天數 90 → 365（讓戰績不會三個月後就消失）。
- 單筆報酬＝結果價 ÷ 突破價 − 1：TP2 用 TP2 價、只達 TP1 還在追蹤用 TP1 價、失效用失效價、過期用到期收盤、追蹤中用最新收盤。
- **分母（樣本）**＝已達 TP1、已達 TP2、失效、過期的筆數；還在追蹤、什麼都沒發生的不計。TP1 率＝曾達 TP1（含後來達 TP2 或失效）÷ 樣本；TP2／失效／過期率＝該狀態 ÷ 樣本；平均報酬只算有報酬資料的樣本；不含手續費與滑價。
- 分組：型態（頭肩底／收斂三角）× 週期，另有各維度合計與全部。
- `retro`＝追蹤開始前就發生的結果（首次啟動或事件早於訊號時間），預設不計入；`anomaly`＝失效價 ≥ 突破價或 TP1 ≤ 突破價（例如部分下降三角被標成向上突破），不計入彙總、不算報酬。

## 系統出錯通知（`scripts/health_alert.py`，只用標準庫）
